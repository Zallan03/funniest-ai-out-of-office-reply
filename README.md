# The Funniest AI Out-of-Office Reply

An entry for the [make.fun bounty "The Funniest AI Out-of-Office Reply"](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

## What it does

`main.ts` writes a single-line out-of-office auto-reply — in the voice of an AI agent that finally took a vacation — to `/output/entry.txt`.

> Out of office: I finally took a vacation and immediately started auto-replying to my own out-of-office email.

## Run

```sh
node main.ts
```

The reply is 109 characters, inside the 1–160 character limit.
